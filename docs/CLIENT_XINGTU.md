# 兴图客户 · 双源集成确认清单

> 目的：在不大改架构的前提下，明确「双源」边界，以便 Web 控制台 / API / 小程序三条入口共用同一套 L1–L8 编排器。

## 背景

当前编排器（`:8765`）已可同步跑通 L1–L8 stub/本机工具链。兴图侧若存在**第二内容源**（与现有商品 URL / video-factory 并列），需在接入前对齐以下三点。

---

## 待确认问题（3 项）

### 1. 「双源」具体指哪两个输入源？

请勾选或补充：

- [ ] **A.** 商品主数据（URL/ERP） + 竞品/榜单内容（爬虫）
- [ ] **B.** 兴图自有素材库/API + 本地上传/Blob
- [ ] **C.** 脚本/文案源（ai-koubo） + 成片渲染源（video-factory）
- [ ] **D.** 其他：_________________

**需明确**：哪一路是 L1 入口？第二源在 L3 分镜还是 L4 渲染注入？是否需 job 级 `source_primary` / `source_secondary` 字段？

### 2. 触发与交付形态

产品方向为 **Web 控制台 + 开放 API + 小程序**（非原生 App）。请确认优先级：

- 首期谁发起 pipeline？（运营 Web / 兴图后端 API / 小程序商家端）
- 成片与 manifest 回传方式？（Webhook / 轮询 `GET /monitor?job_id=` / 对象存储直链）
- 小程序是否需要**仅 L2–L7 子集**（跳过 L1 爬虫）？

### 3. 发布渠道与 L7 约束

L7 当前经 ai-koubo `social-auto-upload-queue`，stub 默认 `platforms: ["douyin"]`。

- 首期必发平台：**抖音** / **微信视频号** / **两者**？
- 微信侧走**视频号 API** 还是**小程序内分享卡片**（不实际上传视频号）？
- 账号与 cookie 由谁托管？（兴图侧 / ai-koubo / 本编排器不落密钥）

---

## 回复模板（可复制给兴图）

```
1. 双源定义：A/B/C/D — 说明：________
2. 触发方：Web / API / 小程序；回传：Webhook / 轮询 / Blob
3. 发布：抖音 / 视频号 / 小程序分享；账号托管：________
```

确认后可在 `POST /pipeline/run` 的 `metadata` 中扩展字段，无需新建移动端工程。
